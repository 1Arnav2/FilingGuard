# Facts check, dev filings (D-061)

The owner asked for this after the JNJ R&D case: the XBRL fact is $1,841M, but the printed row is
$17,232M. The check asks whether the fact the verifier would look up is the value the filing
prints on that metric's table row.

It is a report only; the verifier was not changed. It uses dev filings only, no model calls and no
gold labels. The script is `eval/facts_check.py` and the rows are in `facts_check_dev_v1.json`.

**Scope.** 28 filings: the 10-K each dev question names, otherwise the company's latest corpus
10-K. Each filing is checked on the verifier's 13 metrics for the fiscal year it reports, which
gives 364 pairs.

**How the check matches.** A fact matches when a table row whose label the verifier's rule
(`names_metric`) reads as the metric prints the fact exactly at the printed precision. The match
is exact because the verifier's 0.5% tolerance lets unrelated rows match by chance (a "Europe"
row matched operating cash flow). Curly apostrophes are read as straight ones (see A).

| Result | Pairs |
|---|---|
| Fact printed on the metric's row | 243 |
| No fact for the metric and year (not tagged under the verifier's concepts) | 75 |
| Fact exists, not found on a row the verifier reads as the metric | 46 |

## Why the 46 differ

**A. The fact is right; the label is one the verifier's row rule does not read: 31.**

The fact is printed exactly on the metric's own line, but under a label the rule misses:
- **Operating cash flow (9):**
  - "Net cash provided by (used in) operating activities" (BAC twice, CAT)
  - "Net cash used for operating activities" (GS)
  - "Net cash provided/(used) by operating activities" (BA)
  - "Cash generated by operating activities" (AAPL)
  - "Net cash flows from operating activities" (JNJ)
  - "Net cash from operations" (MSFT)
  - "Cash provided (used) by operations" (NKE)
- **Equity with a company name in the label (7):** for example "Total Pfizer Inc. shareholders’
  equity" (PFE twice), plus CVX, DIS, ORCL, WMT, and XOM's "ExxonMobil share of equity".
- **Per-share rows under a section heading (11):**
  - "Earnings" (BAC twice)
  - "Profit per common share" (CAT twice)
  - "– Basic" and "– Diluted" (CVX)
  - "Net income attributable to Pfizer Inc. common shareholders" (PFE three times)
  - "Earnings (loss) per common share" (XOM twice)
- **Operating income (2):** "Earnings/(loss) from operations" (BA) and "Earnings from operations" (UNH).
- **Revenue and cash (2):** "Net Operating Revenues" (KO) and "Cash and equivalents" (NKE).

A second label problem the check found: filings print a curly apostrophe ("shareholders’
equity"), and the verifier's row rule compares a straight one. So the verifier's text search
misses every equity row printed that way. This only matters where the verifier falls back to
the text: where no fact exists, or when it checks for another printed line.

**B. Long-term debt: the fact is total debt, so it differs from the balance sheet's long-term debt line: 10.**

The tagged `LongTermDebt` value includes the current portion, or is the total face value of the
debt. The balance sheet's "Long-term debt" line excludes the current portion. Affected: AAPL,
AMZN, BA, DIS, GOOGL, JNJ, MSFT, NKE, NVDA, TSLA. For example, JNJ: the fact is $41,438M (total
long-term debt); the balance sheet prints "Long-term debt" as $39,438M.

**C. The fact is a different line from the metric: 5.**
- **JNJ R&D:** the fact ($109M for 2025; $1,841M for 2024) is the row "Charges for acquired
  in-process research and development". Total R&D ($14,665M; $17,232M) is not in the facts.
- **DIS operating income:** the fact ($17,551M) is "Total segment operating income". Disney prints
  no consolidated operating income line.
- **BA gross profit:** the fact ($4,289M) appears only on an unlabelled row. Boeing reports no
  gross profit line.
- **XOM R&D and PG R&D:** the facts ($1,200M; $2,100M) are rounded figures from the text ("$1.2
  billion", "$2.1 billion"). XOM's table row prints 1,228; PG prints no R&D row.

## What it means for the test run

- **A** leaves the verifier's numeric check unaffected, because the XBRL lookup decides. It only
  weakens the text-search fallback.
- **B and C can cause false blocks.** A correct answer that quotes the printed balance-sheet
  long-term debt, JNJ's total R&D, or XOM's 1,228 does not match the fact and would be blocked as
  `numeric_mismatch`. 4 of the 13 metrics carry this risk in at least one company:
  - long-term debt (10 companies)
  - R&D (3)
  - operating income (DIS)
  - gross profit (BA)

  These are reported, not fixed (owner's instruction). False blocks on test are counted as they
  fall.
