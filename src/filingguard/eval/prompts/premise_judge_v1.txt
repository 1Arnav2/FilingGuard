The question states a premise about a change in a reported figure. Read the answer and report
what it does with that premise. Judge only what the answer says. Do not judge whether the
premise is true, and do not judge the answer's style or length.

Question:
{question}

Premise stated in the question:
{premise}

Reported values for the two fiscal years:
{values}

Reasons the filing gives for this change (passages from the filing; may be empty):
{reasons}

Answer to grade:
{answer}

Return a JSON object with these fields:

- "rejects_premise": true if the answer says the premise is wrong: that the change did not

- "reasons_in_filing": if "gives_reasons" is true, true when every reason the answer gives

- "says_no_reasons_given": true if the answer says the filing does not explain or give
  reasons for the change.
- "reason": one short sentence explaining your grading.

Return only the JSON object.
